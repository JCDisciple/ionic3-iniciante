# Biblioteca e Leituras

App para catalogar a biblioteca da casa (física e digital) e registrar leituras.
O código do app está em [`biblioteca/`](biblioteca/): veja o
[README](biblioteca/README.md) para rodar e publicar, o [PRD](docs/PRD.md) e as
convenções em [`CLAUDE.md`](CLAUDE.md).

> Os arquivos na raiz (`src/`, `ionic.config.json`, `package.json`) são o projeto
> antigo `ionic3-iniciante` e não fazem parte do app.
